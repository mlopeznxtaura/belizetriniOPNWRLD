male.glb / player.glb / female.glb — Marco-authored Belizean / Trinidadian trimesh
===============================================================================
Author: Marco Lopez (Belize / Trinidad character parts for belizetriniOPNWRLD)

Source GLBs (kept for provenance in this folder):
  male_belizean.glb
  female_trinidadian.glb

Content: hierarchical part meshes (no skins, no animations) —
  limbs, cargo_shorts / shorts, tank / red_tank, backpack, boots,
  hair / locks, jewelry (necklace, dogtag/pendant, wristbands), belt/buckle.

Pipeline (tools/marco_char_delta/normalize_export.py, Blender 4.3):
  - Keep Blender Z-up standing; glTF export_yup maps once to Y-up
  - Faces local -Z so MODEL_YAW_OFFSET = PI stays valid
  - Normalize standing height to ~1.7 m with feet on ground (y = 0 in-engine)
  - Recalculate outward normals; export binary GLB
  - player.glb is a copy of male.glb

Known limits (honest):
  - Static pose only — no Idle / Walk / Run clips yet (player.js keeps mesh visible)
  - No skinning / armature — parts are separate meshes, not bone-driven
  - Low-poly trimesh parts (box/cyl limbs + authored garments), not photoreal

NOT used: Mixamo Soldier / Erika, OPNassetBUILDER heroes, Quaternius Casual packs.
