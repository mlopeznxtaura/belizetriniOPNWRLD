Content (lowpoly): male_*/female_* part meshes (no skins, no animations), ~4.9k tris each —
  Male: off-white tank, olive cargo shorts + pockets, backpack + straps, beard, 7 top curls, wristbands, necklace
  Female: red tank, khaki shorts, headwrap, 14 locs, backpack + straps, wristbands, necklace
  Single hand mesh (no fingers), no eyelids, no laces.

Pipeline (tools/marco_char_delta/normalize_export.py, Blender 4.3):
  - Source imports lying along Blender -Y at ~5.7 units; rotated -90 deg about X (world matrix),
    anchor-checked (head above boots, nose in front = glTF +Z, MODEL_YAW_OFFSET 0)
  - Normalize standing height to 1.7 m with feet on ground (y = 0 in-engine)
  - Recalculate outward normals; export binary GLB; player.glb is a copy of male.glb

Known limits (honest):
  - Static pose only — no Idle / Walk / Run clips (player.js keeps mesh visible)
  - No skinning / armature
  - Authored gaps: head floats ~5-7 cm above neck; eyes sit inside the haircap (not visible);
    curls/locs point upward (crown look)
